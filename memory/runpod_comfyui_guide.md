# memory/runpod_comfyui_guide.md

## Что это

Главный длинный файл по теме ComfyUI / RunPod / GPU-инфраструктуры.
Это канонический memory-файл для всей длинной темы.

## Статус сейчас

- Статус: в работе.
- Тема длится уже не одну сессию и не должна храниться только в общей памяти.
- Тема связана с отдельным сервером, GitHub-частью, настройкой ComfyUI и организацией долгого техконтекста между сессиями.
- Для всех задач по этой теме Джон, Ева и связанные субагенты должны читать этот файл первым.
- Текущий активный task-log: `logs/tasks/runpod_comfyui_eva_sync.md`.
- Ближайший следующий шаг: держать этот файл главным источником правды и синхронизировать с ним все новые шаги по RunPod / ComfyUI.

## Что уже известно

- Тема признана длинной и межсессионной.
- Пользователь явно указал, что по ней есть важные данные и она длится несколько дней.
- Для этой темы уже требуется специализированная память, которую смогут читать Джон, Ева и другие профильные агенты.
- Пользователь отдельно обозначил, что субагенты должны вести свой лог действий, чтобы Джон мог контролировать их работу.

## Главные цели темы

- Не терять технический контекст по ComfyUI / RunPod между сессиями.
- Держать в одном месте текущий статус, проблемы, решения и следующий шаг.
- Дать Джону и Еве единый файл, с которого можно быстро продолжать работу.
- Связать длинную тему с живым task-log, чтобы был виден не только контекст, но и текущая операционная работа.

## Роли

- Джон — держит общую картину, выбирает исполнителей и собирает результат.
- Ева — основной профильный исполнитель по GPU / media / ComfyUI части.
- Кент — подключается, если есть кодовые или инженерные правки.
- Бэн — помогает декомпозировать длинную цепочку работ, если тема распадается на несколько потоков.

## Открытые проблемы

- Нет гарантии, что вся важная информация по теме уже собрана в одном месте.
- Без дисциплины обновления этот файл может снова отстать от реального статуса.
- Если task-log не обновлять перед новой сессией, Джону будет сложнее понять, на чём реально остановилась работа.

## Ключевые решения

- Этот файл считается главным файлом темы.
- Все новые важные детали по ComfyUI / RunPod надо писать сюда, а не распылять по случайным заметкам.
- Для живой работы по теме используется отдельный task-log.
- Перед новой сессией сначала обновляется task-log по теме, потом этот файл, потом краткая запись попадает в общую память.

## Связанные файлы

- Общая память: `MEMORY.md`
- Индекс памяти: `memory/INDEX.md`
- Дневной лог: `memory/2026-06-21.md`
- Session index: `memory/session-log.md`
- Активный task-log: `logs/tasks/runpod_comfyui_eva_sync.md`

## Правило обновления

После каждого заметного шага по этой теме надо:
1. Обновить `logs/tasks/runpod_comfyui_eva_sync.md`, если шла живая делегация.
2. Обновить этот файл.
3. Добавить краткую запись в `memory/YYYY-MM-DD.md`.
4. При подготовке новой сессии отметить переход в `memory/session-log.md`.
5. В `MEMORY.md` оставить только короткую выжимку и ссылку на этот файл.

## Минимальная структура рабочей записи

- Что сделали.
- Что сработало.
- Что не сработало.
- Где смотреть продолжение.
- Кто делает следующий шаг.
- Какой task-log сейчас активен.
