# memory/runpod_comfyui_guide.md

## Что это

Главный длинный файл по теме ComfyUI / RunPod / GPU-инфраструктуры.

## Статус сейчас

- Тема считается длинной и межсессионной.
- Её нельзя держать только в общей памяти.
- Для всех задач по этой теме Джон, Ева и связанные субагенты должны читать этот файл первым.

## Что хранить здесь

- серверы и доступы на уровне описаний;
- структура пайплайна;
- где лежат workflow;
- какие были проблемы;
- какие решения уже приняты;
- что сломано сейчас;
- ближайший следующий шаг.

## Роли

- Джон — держит картину и управляет задачами.
- Ева — основной профильный исполнитель по GPU / media / ComfyUI части.
- Кент — подключается, если есть кодовые или инженерные правки.
- Бэн — помогает декомпозировать длинную цепочку работ.

## Правило обновления

После каждого заметного шага по этой теме надо:
1. Обновить этот файл.
2. Добавить краткую запись в `memory/YYYY-MM-DD.md`.
3. При необходимости отметить переход в `memory/session-log.md`.
4. Если работа шла через субагента — обновить `logs/tasks/<task-name>.md`.

## Минимальная структура рабочей записи

- Что сделали.
- Что сработало.
- Что не сработало.
- Где смотреть продолжение.
- Кто делает следующий шаг.
