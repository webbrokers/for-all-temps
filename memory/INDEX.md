# memory/INDEX.md

## Что это

Это карта памяти Джона.
Она нужна, чтобы быстро понять:
- что читать первым;
- где лежит длинная тема;
- какой файл является каноническим;
- куда писать новое знание.

## Порядок чтения при старте

1. `MEMORY.md`
2. `memory/INDEX.md`
3. актуальный `memory/YYYY-MM-DD.md`
4. тематический файл по текущей задаче
5. нужный `logs/tasks/*.md`, если есть активная делегация

## Канонические файлы по темам

- `memory/memory_agents.md` — роли агентов, делегирование, task-owner, обучение агентов.
- `memory/memory_infra.md` — модели, runtime, инфраструктура, сервисные правила.
- `memory/runpod_comfyui_guide.md` — длинная тема по ComfyUI, RunPod, GPU и смежной инфраструктуре.

## Операционные журналы

- `memory/session-log.md` — короткий индекс переходов между сессиями.
- `memory/2026-06-21.md` — дневной лог за текущий день.

## Шаблоны

- `memory/DAILY_TEMPLATE.md` — как писать дневные записи.
- `memory/TOPIC_TEMPLATE.md` — как вести длинную тему.
- `logs/task_template.md` — как субагентам вести рабочий лог.

## Правила использования

- Если тема живёт больше одной сессии — заведи отдельный тематический файл.
- Если работа отдана субагенту — заведи task-log.
- Если информация нужна всем — зафиксируй короткую суть в `MEMORY.md`.
- Если это деталь одной темы — храни её в тематическом файле, а не в общей памяти.
