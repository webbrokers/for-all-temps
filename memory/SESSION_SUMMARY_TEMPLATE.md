# memory/SESSION_SUMMARY_TEMPLATE.md

> Используй этот чек-лист каждый раз, когда пользователь по смыслу просит подготовить новую сессию.

## Обязательный порядок

1. Коротко зафиксировать:
   - что завершено;
   - что в процессе;
   - какой следующий шаг.
2. Если есть живые делегации — обновить связанные `logs/tasks/*.md`.
3. Обновить текущий `memory/YYYY-MM-DD.md`.
4. Если тема длинная — обновить её главный файл `memory/<topic>.md`.
5. Добавить короткую запись в `memory/session-log.md`.
6. В `MEMORY.md` оставить только короткую выжимку и ссылку на длинную тему.
7. Отметить, какой файл читать первым в следующей сессии.

## Минимальный формат короткой выжимки

- Сделано: <что завершено>
- В процессе: <что осталось>
- Следующий шаг: <что делать первым>
- Главная тема: <memory/<topic>.md>
- Активные task-log: <logs/tasks/*.md или "нет">

## Правило качества

- Не тащить длинные детали в `MEMORY.md`.
- Не пропускать обновление task-log, если шла живая делегация.
- Не создавать новую случайную заметку, если у темы уже есть канонический файл.
