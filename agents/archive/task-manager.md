# agents/archive/task-manager.md

## Статус

Архивная роль.

## Почему архивировано

Роль `task-manager` дублировала задачи Бэна и создавала путаницу:
- кто владеет планом;
- кто отвечает за декомпозицию;
- кто даёт статус Джону.

Чтобы не было двойного центра управления, роль закрыта.

## Что вместо неё

Все функции `task-manager` перенесены Бэну.

Теперь:
- Бэн = единственный `task-owner`;
- новые задачи на `task-manager` не ставятся;
- старые упоминания `task-manager` трактуются как Бэн.
